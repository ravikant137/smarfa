## Project Context (Smarfa)
- **Stack**: Static HTML + Vanilla JS, deployed via GitHub Pages / Vercel
- **No live backend** — any `fetch(API + '/...')` will 404. Use client-side mocks.
- **Map**: Leaflet.js with Google satellite tiles (`lyrs=s`)
- **Satellite data**: Agromonitoring API (direct CORS calls, no proxy)
- **Location**: `window.userLat` / `window.userLon` (set via GPS or IP fallback)
- **Key files**:
  - `web/index.html` — main app shell + all tab UIs
  - `web/js/dashboard.js` — map init, market ticker, IoT cards
  - `web/js/satellite.js` — NDVI analysis, polygon drawing, crop detection
  - `web/js/weather.js` — weather widget
  - `web/js/config.js` — API keys, app config

## Known Bugs / Gotchas
- Leaflet grey tiles: always call `invalidateSize()` after tab show and on app enter
- Overpass API has no agrarian shops in rural India → use city-name-based fallback
- `_mapInited` declared in both `index.html` and `dashboard.js` — do not add a third
- Cache busters: track current versions: config v4, weather v4, satellite v8, dashboard v7
